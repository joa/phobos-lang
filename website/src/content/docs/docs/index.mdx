Phobos is a tile-based GPU kernel language and an LLM inference engine built
on it. These pages cover both: writing kernels, and running models.

## Writing kernels

- [Language guide](/docs/language/): the language one concept at a time,
  from kernels and tensors to tiles, slicing, reductions and `dot`.
- [Execution context](/docs/ctx/): every `ctx` field, from the grid of CTAs
  down to a single lane, and how per-thread values work.
- [Attributes](/docs/attributes/): one page for each `@` attribute, such as
  `@autotune`, `@launch` and `@tensorcore`.
- [Python](/docs/python/): the same kernels written as Python functions,
  launched on torch or CuPy arrays and autotuned, with Triton's tutorials
  ported.
- [Examples](/docs/examples/): five kernels from the repository, explained.

## Running models

- [Inference](/docs/inference/): quickstart, supported models and formats,
  serving, sampling, benchmarking, the kernel cache and troubleshooting.

## Reference

- [Language spec](/docs/reference/spec/): the complete language, rendered

- [Environment variables](/docs/reference/environment/): every `PHOBOS_*`

- [Benchmarks](/docs/reference/benchmarks/): measured results against

- [Command-line tools](/docs/reference/cli/): the `--help` of every binary.
